# Funghi Meteo

Visore di mappe microclimatiche dei versanti, calibrate sui porcini.

La mappa del giorno viene preparata sul PC e letta dall’app. I colori sono **stime empiriche**: non sono prova della presenza di funghi né garanzia di raccolto.

## Sito pubblico

- Live: https://rockjoel.github.io/funghi-meteo/
- Contenuti: home + privacy
